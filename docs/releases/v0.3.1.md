# CairnShop v0.3.1 — Developer Scripts and Non-Destructive Seed

Tooling patch. No API or schema changes.

## Highlights

- `scripts/dev-up.sh`, `dev-down.sh`, `dev-status.sh` for the VS remote
  development layout. They auto-detect the VS build/source directories, so the
  daily flow is one command.
- `dev-up` starts MySQL, CairnKV, migrations, seed, config seed, backend, and
  frontend, then prints the access URLs.
- `dev-down` stops the frontend and backend, and keeps MySQL and CairnKV
  running by default so configuration keys survive. Use
  `STOP_CAIRNKV=1 bash scripts/dev-down.sh` to stop the cluster too.
- `seed` is now insert-only (`INSERT IGNORE`): re-running it no longer resets
  price, stock, status, or name of existing products/categories.

## Notes

- `dev-up.sh` uses local defaults (`127.0.0.1`, user/password `cairnshop`) and
  optionally sources `$SRC/.env`; the production env with Docker service names
  is not sourced.
- The seed change needs a backend rebuild; the normal build + `ctest` applies.
- CairnKV dev data still lives under `/tmp/cairnkv-cluster` and is wiped when
  `run-cluster.sh` starts a fresh cluster. Keep the cluster running between dev
  sessions to keep config keys; production deployments use Docker volumes.
