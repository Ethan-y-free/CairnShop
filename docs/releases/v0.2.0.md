# CairnShop v0.2.0 — Cart, Checkout and the Config Plane

Cart and checkout are working end to end, with promotions driven by CairnKV
and an idempotent order transaction.

## Highlights

- Cart API: view / add / update / remove.
- Checkout transaction: cart lock, conditional stock decrement, order,
  order items, pending payment, and cart clear in one MySQL transaction.
- Promotions: percent / fixed with threshold, priority, and time window;
  the winning rule and `config_version` are stored on the order.
- Idempotent checkout: `Idempotency-Key` is reserved inside the same
  transaction; replays return the stored response and never create a second
  order.
- Mock payment and cancellation (with stock restoration).
- Order list / detail with ownership checks.
- CairnKV config plane: vendored v1.0.1 client, multi-seed connection,
  500 ms stale-cache refresh, linearizable ops reads, `seed-config`, and
  fail-closed behavior.

## Validation

- `ctest`: 1/1 (crypto, validation, promo).
- W7 smoke (`scripts/w7-smoke.sh`):
  - cart subtotal 12900, welcome10 discount 1290, total 11610;
  - duplicate `Idempotency-Key` returns the same `order_no`;
  - pay -> status `paid`;
  - admin `ops/config` returns 4 keys, `connected=true`, `stale=false`,
    `age_ms` below 500.
- Fail-closed: `checkout_enabled=false` returns `503 checkout_disabled`;
  restoring the flag re-enables checkout.

## Known limits

- Prepared statements are still on the hardening backlog; parameters are
  escaped through one helper.
- Config writes / version history / rollback are W8 work.
- No frontend, rate limiting, metrics endpoint, or CI yet.
- Order list returns headers only; details include items.

## Upgrade

- Apply the existing schema (no new migration in this release).
- Start a 3-node CairnKV cluster and run `cairnshop-backend seed-config`
  before the first checkout.
- Set `CAIRNSHOP_CAIRNKV_ADDRS` to the three seed addresses.
