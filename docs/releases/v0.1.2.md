# CairnShop v0.1.2 — Plain Product README

Documentation-only patch. No code, API, or schema changes.

## Highlights

- README rewritten in a plain product voice: what CairnShop is, feature
  status, architecture, data split, quick start, API, security, validation,
  project structure, documents, and roadmap.
- Removed defensive framing ("not a demo", "first real consumer", "rather
  than a self-serving demo") and the rationale section that read like
  internal notes.
- CairnKV appears only as a factual dependency: an independent Raft KV repo,
  pinned by tag, storing feature flags, promotions, global switches, and
  configuration history. Business and transactional data stay in MySQL.

## Validation

- No code changes. The v0.1.0 build, `ctest` 1/1, migrations/seed, and API
  smoke results still apply.
