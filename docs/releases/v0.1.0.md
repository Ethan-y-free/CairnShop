# CairnShop v0.1.0 — W6 Backend Skeleton

First working slice of CairnShop: repo, MySQL schema, migrations/seed,
authentication with roles, and a read-only catalog API. CairnKV integration
starts in W7; this release is MySQL-only.

## Highlights

- C++20 modular monolith skeleton: `backend/{src,include,tests}`, vendored
  `cpp-httplib` + `nlohmann/json`, CMake + Ninja.
- MySQL 8 schema for users, sessions, catalog, carts, orders, payments,
  idempotency keys, and audit logs (`db/migrations/0001_init.sql`).
- `cairnshop-backend migrate` and `seed` subcommands; seed creates an admin,
  3 categories, and 6 active products.
- Auth: register / login / logout / me; PBKDF2-SHA256 passwords, SHA-256
  session tokens, HttpOnly + SameSite=Lax cookie, `customer` / `ops` / `admin`
  roles.
- Catalog: category list, product list (`category_id` / `q` / `limit` /
  `offset`), product detail; ops create/update endpoints with role checks.
- JSON structured logs, `/healthz`, `/readyz`.

## Validation

- Build: Debug (Linux-GCC, Ninja) — clean.
- `ctest`: 1/1 (crypto + validation suites).
- `migrate`: `0001_init.sql` applied.
- `seed`: admin + 3 categories + 6 products.
- API smoke:
  - `/healthz`, `/readyz` -> `ok`;
  - catalog list returns seeded products;
  - register/login/me returns the expected user;
  - admin creates product `TEST-001` (201);
  - customer access to `/api/v1/ops/...` -> 403.

## Known limits

- SQL parameters are escaped with `mysql_real_escape_string`; prepared
  statements are part of W7 hardening.
- No caching layer, rate limiting, CSRF double-submit, or metrics endpoint yet.
- CairnKV is not wired in this release; W7 adds flags/promos/global switches
  via `libcairnkv` pinned to `CairnKV v1.0.0`.
- Frontend starts in W8.

## Data split (architecture A)

MySQL stores transaction data (users, sessions, products, stock, orders,
payments, audit). CairnKV will store the configuration plane (feature flags,
promotions, global checkout switches, config version/history). Orders will
persist `promo_snapshot` + `config_version` for replay.
