# CairnShop v1.0.0 — Release

CairnShop is a feature-flag and promotion driven e-commerce platform with a
Vue3 storefront, an operations console, and CairnKV as the strongly
consistent configuration plane.

## Highlights

- **Storefront**: catalog, product detail, register/login, cart, promotions,
  idempotent checkout, mock payment, order list.
- **Operations console**: versioned config editor with history and rollback,
  product management, audit log, MySQL/CairnKV/config-cache status.
- **Config plane**: CairnKV `v1.0.1` pinned through a vendored client;
  multi-seed connection, 500 ms stale cache, linearizable ops reads, fail
  closed on stale or disabled checkout.
- **Security**: PBKDF2-SHA256 passwords, hashed session tokens, HttpOnly
  cookies, role checks, rate limits (login 5/min/IP, register 60/min/IP,
  checkout 10/min/user, ops 30/min/user), Origin/Host CSRF check.
- **Observability**: JSON request logs with `request_id` and `latency_ms`,
  `/metrics` Prometheus counters, `/healthz` and `/readyz`.
- **Delivery**: GitHub Actions CI (backend build + ctest, frontend build),
  e2e script, oversell test, Dockerfiles and Compose profiles for VPS TLS and
  Cloudflare Tunnel.
- **UI**: page transitions, card hover, skeleton loading, staggered product
  entrance, cart badge, animated status tiles, responsive layouts.

## Known limits

- SQL uses a centralized escape layer instead of prepared statements.
- Rate limits are in-process; multi-instance needs a shared store.
- CairnKV has no snapshot/WAL compaction yet.
- The public deployment (VPS or Cloudflare Tunnel) still needs a live run.
- CairnKV kill-leader/partition drilling for CairnShop is documented in
  `docs/DEMO.md`, not automated in CI.

## Upgrade

- Apply migrations; the schema is unchanged since v0.1.0.
- Ensure a CairnKV cluster is reachable and run `seed-config` once.
- Rebuild the backend and frontend; pin `CairnKV v1.0.1`.
